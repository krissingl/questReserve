## Ticket 5 of 9 — GitHub #65

**Title:** Implement AuthContext

**Description:**
Create `src/contexts/AuthContext.tsx` with the exact interface shape from `docs/planning/ui-strategy.md` Section 4.4. This is the single source of truth for auth state across the application and is a prerequisite for the role-scoped layout guards in Ticket 6.

**Acceptance Criteria:**
- [ ] `AuthUser` interface, `UserRole` type, and `AuthContextValue` interface are defined exactly as specified in Section 4.4 of `docs/planning/ui-strategy.md`
- [ ] `AuthContext` is provided at the application root, above the router
- [ ] `login` calls `auth.api.ts` (a stub implementation is acceptable in this phase)
- [ ] `logout` clears `user`, `token`, and `role` from state, removes the token from storage, and redirects to `/login`
- [ ] Token storage uses in-memory React state as the primary mechanism — `localStorage` is not used as the permanent storage solution
- [ ] A `useAuth` convenience hook is exported from the same file, returning the context value

**Dependencies:** Ticket 4

- [ ] Navigating to `/customer` without being authenticated redirects to `/login`

## Ticket 7 of 9 — GitHub #67

**Title:** Implement the API client layer

**Description:**
Create the Axios-based API client and the `auth.api.ts` stub module. This establishes the API layer pattern from Section 4.3 of `docs/planning/ui-strategy.md` that all subsequent phases must follow.

**Acceptance Criteria:**
- [ ] `src/api/client.ts` creates a single Axios instance with `baseURL` set from `import.meta.env.VITE_API_URL`
- [ ] The request interceptor reads the token from `AuthContext` and injects `Authorization: Bearer <token>` on every outgoing request
- [ ] The response interceptor catches 401 responses, clears auth state, and redirects to `/login`
- [ ] `src/api/auth.api.ts` exists as a stub module with at least a `login` function signature demonstrating the pattern
- [ ] `src/api/client.ts` is the only file that imports `axios` directly — no other file in the project imports `axios` directly
