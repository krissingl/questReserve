## 1. Colour Palette

### Primary Colours

* **Obsidian** — `#0B0F1A`
  Primary background colour. Deep blue-black used for main application surfaces.

* **Arcane Violet** — `#5B2A86`
  Primary brand colour. Used for key interactive elements and brand identity.

* **Spell Gold** — `#D4AF37`
  Accent colour. Used for highlights, premium elements, and key callouts.

### Secondary Colours

* **Runic Blue** — `#2E6F95`
  Used for links, secondary buttons, and interactive states.

* **Ember Red** — `#A23E48`
  Used for warnings, high-risk indicators, or dangerous dungeon classifications.

* **Mist Grey** — `#A7B3C2`
  Used for secondary text, borders, and muted UI elements.

### Utility Colours

* **Success (Enchanted Green)** — `#3BA55D`
* **Error (Curse Red)** — `#D64545`
* **Surface Dark** — `#121826` (cards, panels, containers)

### Theme Guidance

* Dark mode is the primary theme.
* UI should emphasize high contrast and readability.
* Accents may include subtle glow or gradient effects to evoke magical elements.

## 2. Typography

### Primary Typeface (Body / UI)

* `"Inter", "Segoe UI", system-ui, sans-serif`

### Secondary Typeface (Headings)

* `"Cinzel", "Times New Roman", serif`

### Optional Accent Typeface

* `"Uncial Antiqua"` (to be used sparingly for decorative purposes only)

### Typography Guidelines

* Maintain high readability across all functional UI.
* Avoid decorative fonts in body or dense content areas.
* Use serif type selectively to introduce tone without sacrificing usability.

## 3. Logo Requirements

### Status

* No finalized logo assets provided.

### Direction

* Logo should incorporate:

  * A tower motif
  * Magical elements (e.g., runes, aura, or energy spiral)
  * Optional subtle reference to scheduling (e.g., circular or orbital structure)

### Style Requirements

* Must work in monochrome and full colour
* Should scale well across UI (icon to header size)
* Prefer minimal and clean execution over detailed illustration

### Delegation

* QuestReserve team is authorized to design and propose initial logo concepts.

## 4. Aesthetic Direction

### Core Style

* Dark fantasy blended with modern SaaS UI patterns

### Design Principles

* Functionality and clarity take priority over stylistic elements
* Visual design should feel elegant and intentional
* Fantasy elements should enhance, not distract from usability

### Tone Characteristics

* **Functional:** High priority
* **Elegant:** High priority
* **Mysterious:** Moderate
* **Playful:** Low

### Visual Suggestions

* Subtle glow effects on interactive elements
* Minimal rune or arcane pattern usage in backgrounds
* Layered surfaces to create depth (cards, panels)
* Clear hierarchy for information-heavy screens

## 6. Product Experience Intent

### Target Users

* Dungeon Owners (primary clients)
* Adventure Parties (end users)

### Experience Goals

* **Dungeon Owners:** feel in control, organized, and supported
* **Adventure Parties:** feel curiosity, excitement, and clarity when booking
* **All Users:** trust the scheduling system and platform reliability

### UX Considerations

* Clear availability and scheduling visibility
* Strong differentiation between dungeon difficulty levels
* Intuitive browsing and filtering system
* Consistent feedback for user actions (booking, cancellation, etc.)

## 7. Notes & Constraints

* The platform is a professional service, not a game interface
* Thematic elements should remain subtle and refined
* Accessibility and readability should not be compromised for style
